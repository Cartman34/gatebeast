OB-010 — plan de composition de l'image d'usage

Grille 7 × 7 — source : assets/poc/cloture/plan-composition-OB-010-usage.svg

Clôture OB-010. Carré fermé, une case entre chaque angle et chaque intersection ; croix centrale ; quatre antennes d'une case vers l'extérieur, une par côté, partant d'une case entre un angle et une intersection.

Un point : cette case porte un sujet. Une branche : elle rejoint la case de ce côté-là. Deux cases voisines sans branche entre elles ne se rejoignent pas.

CH-019 — plan de composition de l'exemple d'usage

Grille 7 × 7 — source : assets/poc/sol/plan-composition-CH-019-usage.svg

Chemin de terre battue CH-019 seul, sur fond transparent : un exemple d'usage montre le sujet et rien d'autre. Le chemin se pose ensuite sur n'importe quel sol, qui n'a pas à être dans son image.

Un chemin est plat : le moteur peut pivoter ses formes, donc cinq dessins suffisent — extrémité, ligne, angle, trois branches, croisement. Cette composition les exerce tous les cinq.
